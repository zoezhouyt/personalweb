# Photo plates for the sign-off

Drop four images in here, named exactly:

- `dance.jpg`      competitive dance
- `training.jpg`   ballet, cello, guzheng
- `curation.jpg`   curatorial work in the UAE and Saudi Arabia
- `rooms.jpg`      anything that reads as "four languages, many rooms"

Portrait crops work best: the plates are 4:5 and the image is centred and cropped
to fill. Roughly 900px on the short edge is plenty. Until a file is present the
plate renders as an empty block rather than a broken image, so the page is safe
to ship half-filled.
